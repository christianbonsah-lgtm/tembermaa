## 🍲 TATA - Gastronomie & Héritage Africain

Un site web vitrine moderne, élégant et entièrement interactif dédié à la mise en valeur de la gastronomie africaine raffinée. 

Ce projet est une solution web monopage (*Single Page Application*) clé en main, conçue avec **React** et **Tailwind CSS**, incluant la gestion d'un menu dynamique, d'un panier de commande et d'un système de réservation.

---

## ✨ Fonctionnalités

- 🍽️ **Menu dynamique & filtrable** : Navigation fluide par catégories (Plats, Boissons, Desserts).
- 🛒 **Système de commande / Panier** : Ajout de plats au panier, calcul automatique du total et récapitulatif.
- 📅 **Module de réservation** : Formulaire de réservation de table en ligne avec confirmation dynamique.
- 📱 **Design Responsive & Dark Mode** : Interface adaptée aux mobiles, tablettes et ordinateurs dans une ambiance sombre et raffinée.
- ⚡ **Prêt pour le déploiement** : Fichier HTML unique autonome, déployable instantanément (Netlify, Vercel, GitHub Pages).

---

## 🛠️ Technologies utilisées

- **HTML5 / CSS3**
- **Tailwind CSS** (via CDN)
- **React 18** (via CDN / Babel)
- **FontAwesome** (Icônes)

## 🚀 Déploiement rapide

### Déploiement local
Il suffit de télécharger ou cloner ce dépôt, puis d'ouvrir le fichier `index.html` directement dans n'importe quel navigateur web. Aucun serveur d'installation (`npm/node`) n'est requis.

### Déploiement sur GitHub Pages
1. Rendez-vous dans les **Settings** (Paramètres) de ce dépôt GitHub.
2. Cliquez sur l'onglet **Pages** dans le menu latéral.
3. Dans la section **Build and deployment**, sélectionnez la branche `main` (ou `master`) comme source.
4. Cliquez sur **Save**. Votre site sera en ligne en quelques secondes !
